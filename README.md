# Scho

A full-stack personal organization application for capturing and managing tasks, reminders, notes, and saved links in one centralized platform.

## Overview

Scho is designed to simplify personal organization by providing a dedicated space to capture, organize, and retrieve everyday information.

Inspired by the limitations of using messaging applications as personal storage tools, Scho aims to provide a lightweight and accessible alternative for managing information across desktop and mobile devices.

## Features

The following features are planned for the application:

- **Tasks** — Create, organize, and track tasks.
- **Reminders** — Schedule reminders for important activities.
- **Notes** — Capture and manage personal notes.
- **Saved Links** — Store and organize useful links.
- **Centralized Organization** — Access personal information from one place.

## Getting Started

### Prerequisites

Ensure the following are installed:

- Node.js (a version supported by the project)
- pnpm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/dreyyan/scho.git
   cd scho
   ```

2. Install dependencies:

   ```bash
   pnpm install
   ```

3. Start the development server:

   ```bash
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

| Command | Description |
| --- | --- |
| `pnpm dev` | Start the development server |
| `pnpm build` | Create a production build |
| `pnpm start` | Start the production server after building |
| `pnpm lint` | Run ESLint |
| `pnpm exec tsc --noEmit` | Check TypeScript types without generating files |
